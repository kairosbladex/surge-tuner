# 服务→区域策略映射表

本目录定义了各境外服务应分配的默认区域策略组。
Agent 在生成配置时，应根据此表为每个服务分配最优区域。

## 映射原则

| 原则 | 说明 |
|------|------|
| **速度优先** | 选择离用户最近的可用节点（如 Telegram 选香港） |
| **解锁优先** | 部分服务需特定地区 IP（如 Netflix 需美国/新加坡） |
| **风控规避** | AI 服务避开香港/中国大陆 IP，否则被封 |
| **直连加速** | 国内有 CDN 的服务默认直连（如 Apple、微软部分服务） |
